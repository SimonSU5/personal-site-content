## 核心总口诀

> **协议优先级（Preference）：数值越小越优先（跨协议对比）**
> 
> **同协议内部 Cost‑度量值：数值越小越优先（协议内选路）**
> 
> 选路顺序：先比较路由优先级 → 优先级相等再比较 Cost

---

| -------------------------- | ----- | ------------------------ |
| Direct 直连路由                | 0     | 最高、不可修改                  |
| OSPFv2/v3 区域内、域间内部路由       | 10    |                          |
| IS‑IS Level‑1              | 15    | 区域内路由                    |

| DHCP‑UNR 动态用户路由            | 60    |                          |

> 优先级取值区间：1‑255；255 代表路由不可信任、不会放进路由表

## 二、各 IGP 协议 Cost（度量值）默认值 & 计算规则

### 1. OSPFv2 / OSPFv3

1. 默认参考带宽：**100‑Mbps**
2. 公式：`接口Cost = 参考带宽 ÷ 接口物理带宽`，计算结果＜1 则强制取值 = 1
3. 各速率接口默认 cost

| 接口带宽       | OSPF 默认 Cost |
| ---------- | ------------ |
| 10M        | 10           |
| 100M       | 1            |
| 1G/10G/25G | 1            |
- 路径总开销：沿途所有出接口 Cost 累加
- 命令修改参考带宽 `bandwidth‑reference 1000`（单位 Mbps）

### 2. IS‑IS

- **所有接口默认 cost = 10**，不受带宽影响
- 整条路由开销 = 链路开销累加
- L1、L2 独立 cost

### 3. RIP

- 度量：跳数 (Hop‑count)
- 默认接口开销 = 1；越小优先；最大有效跳数 15，16 代表路由不可达

### 4. BGP（无 Cost，依靠 BGP 属性依次选举最优路由）

BGP 选路关键点：

1. 本地 Preference‑Value 越大优先
2. Local‑Pref 越大优先
3. AS‑Path 越短优先
4. MED 越小优先
5. EBGP 优于 IBGP

## 三、二层协议开销 / 优先级（STP、MSTP、VRRP、LACP）

> **二层路径开销 Cost 依旧越小越优先**

### 1. MSTP/RSTP/STP（华为 legacy 私有标准）华为

表格

|端口速率|默认路径开销|
|---|---|
|10M|2000|
|100M|200|
|1G|20|
|10G|2|

IEEE‑802.1d‑1998 标准：10M=100、100M=19、1G=4

> 根端口选举：到达根桥总开销最小优先

### 2. VRRP

- VRRP 优先级：**数值越大越优先**；默认优先级 100；取值 1‑254；255 代表 IP 拥有者

> 此处极易混淆！VRRP 优先级和路由优先级规则相反，越大优先

### 3. LACP

- 系统优先级：数值越小越优先
- 端口优先级：数值越小越优先，默认 32768

## 四、组播协议选举优先级

1. PIM‑SM RP 选举：**RP 优先级数值越小越优先**，默认优先级 0
2. DR 选举（OSPF/PIM）：接口优先级越大优先；优先级相同比较接口 IP 大的优先

## 五、考试易错点整理

1. 路由表优先级（preference）：**越小越好**
2. IGP 度量 cost：**越小越好**
3. VRRP 设备优先级：**越大越好**（高频坑）
4. LACP 系统 / 端口优先级：越小越好
5. RP 选举优先级：越小越好
6. OSPF 内部 10、OSPF 外部 150，外部路由可信度很差
7. IS‑IS L1(15)＞L2(18)
8. IBGP 优先级 255，只要 IGP 路由存在永远优选 IGP

## 清单

1. 直连 0＞OSPF 内部 10＞IS‑IS L1‑15＞EBGP20＞IS‑IS L2‑18＞静态 60＞RIP100＞OSPF 外部 150＞IBGP255
2. OSPF 千兆口 cost=1；IS‑IS 所有接口 cost=10
3. VRRP 默认优先级 100，越大优先；其余绝大多数协议优先级越小优先


（Hello 保活时间 / 优先级 Preference / Cost 度量 全套默认值、优先规则；纯华为设备，适配 HCIE‑Datacom）

> 前置核心铁律（必背）
> 
> 1. 路由‑Preference（路由优先级）：**数值越小越优先**
> 2. IGP 路径 Cost / 开销：**数值越小越优先**
> 3. 特殊例外：VRRP 优先级、PIM‑DR 接口优先级 **数值越大越优先**

# 汇总

1. 优先级排序（从小到大）
    
    `直连0 > OSPF内部10 > IS‑IS L1‑15 > EBGP20 > IS‑IS L2‑18 > 静态60 > RIP100 > OSPF外部150 > IBGP255`
2. Hello 秒数速背

- OSPF10、IS‑IS10、BGP60、LDP5、PIM30、VRRP1、STP‑BPDU 2

3. 特殊坑点

- VRRP：**越大优先**；其余绝大多数协议优先级越小优先
- OSPF 千兆 cost=1；IS‑IS 所有接口 cost 固定 10
- 接口调用 ACL 末尾隐式 deny‑all；traffic‑policy 未匹配流量放行
