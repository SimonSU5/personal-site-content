## 实验环境准备

![[Pasted image 20260910130929.png]]

1. 设备管理器中增加环回口网卡，MicrosoftKM-TEST环回适配器。
2. 配置IP为不容易和其他网段冲突的地址，此处配置192.168.100.1/24
3. 重启电脑后，npcap可以识别到此网卡。
4. 打开ensp，新建cloud1，做好新网卡到内部udp的映射。
	![[Pasted image 20260908163417.png]]

5. 防火墙USG6000中，对int ge 0/0/0进行配置，配置如下：
	interface GigabitEthernet0/0/0
	 undo shutdown
	 ip binding vpn-instance default
	 ip address 192.168.100.100 255.255.255.0
	 alias GE0/METH
	 service-manage https permit
	 service-manage ping permit
6. 连接防火墙 ge 0/0/0和cloud1的ge 0/0/0，此时本机cmd能ping通防火墙管理口。在本机浏览器中打开https://192.168.100.100:8443，即可登陆防火墙管理页面。
	![[Pasted image 20260908164730.png]]

## 防火墙虚拟化

1. 一台设备中部署逻辑隔离，使用不同的虚拟系统进行业务隔离
2. 每个虚拟服务器作为数据中心的网关和NAT设备
3. 根系统：防火墙主系统
4. 虚拟系统/虚拟化
	1. 虚拟系统：有独立的资源、独立配置、独立安全功能、独立路由表——可以看成是一个独立防火墙
5. 虚拟接口：
	1. 虚拟系统之间可以通过虚拟接口互访 virtual-if，根系统自动产生virtual-if0
	2. 本质为逻辑接口
	3. 虚拟接口必须配置IP地址，并且加入安全域才可正常工作
6. 虚拟系统访问根系统
	1. 每个虚拟系统都有一个路由表，每个虚拟系统都是网状组网连接。

## 防火墙实验



1. 要求：
	1. A，B，C部门不能互访
	2. A能够完全访问Internet
	3. B只有https流量能够访问Internet
	4. C只有PC3能够访问Internet
	5. A能够访问C的server1
2. 步骤
	1. vsys初始化：
		1. vsys enable
		2. vsys name xxx
	2. resource-class 配置，用于vsys资源配给
		1. resource-class r1
		2. resource-item-limit session reserved-number 20 maximum 100——会话保证数20，最大值100
	3. vsys资源配给
		1. vsys name xxx
		2. assign int g 1/0/1
		3. assign resource-class r1
	4. 切换到vsys下
		1. switch vsys xxx
	5. 每个vsys都将下行口加入trust zone，对外对接的接口（virtual-if）加入untrust zone。
		1. firewall  zone trust
		2. add int g 1/0/x
		3. firewall zone untrust
		4. add int virtual-ifx
	6. 接口配置IP
		1. int g 1/0/x
		2. i a 10.0.0.1 24
		3. service-manage ping permit ——用于测试接口
		4. 子接口配置——配置顺序不能换
			1. 根墙下创建子接口
			2. 根墙下：vsys name vfw3下assign子接口，此时子接口中的所有配置将被抹除
			3. 根墙下：vlan-type dot1q 10——直接添加子接口终结vlan
			4. switch到vsys下：添加ip add
	7. 配置安全策略
		1. A
			1. 允许所有流量：security_policy \n rule name permit_all\n source-zone trust\n destination-zone untrust\n action permit
		2. B
			1. 允许http通过：security_policy \n rule name permit_all\n source-zone trust\n destination-zone untrust\n service icmp http https action permit
		3. C
			1. 允许http通过
			2. 允许A的主机流量访问C服务器地址security_policy \n rule name permit_all\n source-zone trust\n destination-zone dmz\n service icmp http https\n source-address 10.0.11.0 24 action permit
	8. 配置路由
		1. A
			1. 默认路由指向virtual： ip route-static 0.0.0.0 0.0.0.0 public
			2. 这里的public就是指根防火墙
		2. B
			1. 默认路由指向virtual： ip route-static 0.0.0.0 0.0.0.0 public
		3. C
			1. 默认路由指向virtual： ip route-static 0.0.0.0 0.0.0.0 public
			2. 回到**根墙**，配置 ip route-static vpn-instance vfw1 10.0.14.0 24 vpn-instance vfw3 \n ip route-static vpn-instance vfw3 10.0.11.0 24 vpn-instance vfw1[双向放通]
	9. 根墙配置
		1. 将virtual-if0加入trust
		2. 将出接口加入untrust
		3. 添加安全策略
			1. A
				1. trust到untrust，IP限制，放通
		4. 默认路由添加
		5. nat策略添加
			1. nat-policy name PAT
			2. source-zone和destination-zone
			3. action source-nat eazy-ip
