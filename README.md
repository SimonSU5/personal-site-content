# Personal Site Content

个人网站的内容仓库，存储博客文章、作品集等 Markdown 文件。

## 目录结构

```
personal-site-content/
├── config/              # 配置文件
├── blogs/               # 博客文章
│   ├── YYYY/MM/         # 按年月归档
│   └── drafts/          # 草稿（不会同步到网站）
├── works/               # 作品集
├── snippets/            # 代码片段
└── assets/              # 资源文件
```

## 博客文章格式

文件命名格式：`YYYY-MM-DD-slug.md`

Frontmatter 模板：
```yaml
---
title: 文章标题
excerpt: 文章摘要
category: 分类
tags: 标签1, 标签2
cover: assets/covers/image.jpg
---
# 正文开始

文章内容...
```

## 作品集格式

文件命名格式：`project-slug.md`

```yaml
---
title: 项目名称
description: 项目描述
cover: assets/covers/project-cover.jpg
tech: React, TypeScript, Node.js
demo: https://demo.example.com
repo: https://github.com/user/repo
---
# 项目详情

项目介绍...
```

## 同步方式

内容更新后推送到 GitHub，网站会自动同步。

## 工业运维类技术博客封面统一设计原则（写实工业风·专属规范）

本规范基于用户选定的**金属冶炼企业跨省双跨排障·写实工业科技风**封面定稿，适配所有政企运维、网络工程、企业项目类博客封面，统一视觉调性、画面逻辑、光影质感，与BGP/OSPF/RIP网络笔记封面形成系列化统一，为后续所有同类封面制作的标准准则。

### 一、核心整体原则（通用底线）

- **纯无文字设计**：画面零文字、零水印、零LOGO、零标注，所有主题信息由画面视觉承载，适配博客头部展示，不遮挡标题文字。
    
- **固定画幅比例**：统一16:9横版构图，适配绝大多数技术博客、公众号、文档封面展示场景。
    
- **暗调高级基调**：以深色、黑灰低饱和为基底，拒绝亮色、高饱和花哨画面，贴合运维、工程、政企项目的专业严谨属性。
    
- **虚实结合构图**：实景行业场景打底 + 科技网络元素叠加，兼顾业务真实性与技术专业性，区别于纯插画、纯流水线普通封面。
    

### 二、画面场景选材原则（行业写实核心）

针对制造业、工业厂区、政企专线、工程排障类主题，实景素材严格遵循以下标准：

- **场景真实具象**：拒绝抽象虚化素材，选用对应行业实景场景（冶炼高炉、钢结构厂房、工业管线、智能车间、政企机房等），画面具备真实工业质感。
    
- **氛围沉稳厚重**：优先远景、全景厂区镜头，不使用近距离特写、生活化场景，凸显大型企业、工程项目的规模感与专业性。
    
- **色调统一冷调**：主色调为工业冷灰、深黑、金属银，低饱和度，杜绝暖黄、暖橙温馨色调，贴合工业运维、网络故障排查的硬核技术属性。
    

### 三、技术元素叠加原则（网络运维专属）

为贴合网络工程、专线运维、故障排障、路由协议主题，统一叠加科技可视化元素，形成专属系列特征：

- **核心元素固定**：半透明光纤拓扑线条、网络节点、跨省链路、数据流动线条，弱化UI感，融入实景画面，不突兀、不廉价。
    
- **故障主题专属标识**：故障排查、线路中断类主题，点缀**低饱和红色微光故障点**，作为视觉焦点，精准呼应“排障、断链、抢修”核心主题，无夸张特效。
    
- **链路逻辑贴合主题**：跨省、双跨、专线项目，必做**双向平行双线链路**；单链路、路由学习类主题，适配对应单线、网状拓扑，逻辑严谨不随意。
    
- **元素层级克制**：实景底层为主，科技线条上层为辅，科技元素不遮挡工业主体，仅起到点明技术属性、提升科技感的作用。
    

### 四、光影与质感原则（高级电影感）

- **电影级景深光影**：画面低噪点、高质感，背景轻微虚化，主体清晰，层次分明，杜绝高清生硬实拍、滤镜过重、模糊糊边问题。
    
- **光影统一暗沉**：整体暗光环境，局部设备、线条微光提亮，明暗对比柔和，视觉高级不刺眼，适配博客深色/浅色页面兼容展示。
    
- **材质真实还原**：保留工业金属、钢结构、厂区设备的原生肌理，不扁平化、不卡通化，维持写实硬核的工程质感。
    

### 五、系列统一适配原则（衔接全网笔记）

- **风格互通**：介于纯矢量协议封面（BGP/OSPF/RIP）和纯工业实景封面之间，形成「行业实景+网络技术」的专属过渡风格，整套笔记视觉体系连贯统一。
    
- **主次逻辑一致**：所有封面遵循「场景打底、技术点睛、无文字干扰、暗调高级」的固定逻辑，批量观感整齐，辨识度极高。
    
- **适用场景全覆盖**：可通用在企业运维、厂区网络、专线排障、政企项目、工业网络改造等所有工程类技术博客封面。
    

### 六、禁止踩坑细则（硬性标准）

- 禁止任何文字、水印、贴纸、装饰图案；
    
- 禁止高饱和亮色、暖色调、卡通插画、扁平化风格；
    
- 禁止科技元素过重遮挡实景主体、特效杂乱刺眼；
    
- 禁止画面模糊、噪点过多、构图拥挤或留白失衡。

## 网络协议学习笔记技术博客封面统一设计原则（极简科技写实风·专属规范）

本规范基于BGP、OSPF、RIP等网络协议学习笔记封面风格定制，专属**技术学习、协议讲解、网络科普**类博客封面，区别于工业运维项目封面，形成独立、统一、极简高级的笔记系列视觉体系，为后续所有网络学习笔记封面制作标准准则。

### 一、核心整体原则（笔记类通用底线）

- **极简文字适配设计**：支持搭配极简主题文字（笔记标题、技术关键词），字体简约高级、排版规整克制，不堆砌、不花哨；画面留白充足，文字与画面融合度高，不抢视觉主体，整体干净通透。
    
- **固定16:9标准画幅**：统一横版构图，适配技术博客、文档封面、学习课件、公众号头图等全场景展示。
    
- **低饱和科技暗调基调**：以深黑、深灰、藏蓝为基底，拒绝高饱和亮色、花哨配色，贴合技术学习、理论研究的理性、严谨氛围。
    
- **极简抽象科技构图**：摒弃复杂实景场景，以**拓扑线条、网络节点、几何架构**为核心，轻量化科技质感，适配协议原理、路由学习、网络理论类内容。
    

### 二、画面视觉选材原则（协议笔记专属）

针对路由协议、网络原理、技术学习类笔记，画面素材严格遵循轻量化、专业化、抽象化标准：

- **纯科技抽象元素为主**：不使用工业厂区、设备实景、人物场景，核心素材为网络拓扑、节点连线、数据链路、几何网格、流光线路等纯技术元素。
    
- **画面干净轻量化**：杜绝堆砌复杂元素、冗余特效，画面留白充足，整体清爽通透，符合学习笔记“简约、干货、专业”的定位。
    
- **配色统一克制**：主色为科技蓝、冷银、浅青微光，辅助色为深灰底色，无多余杂色，整套系列配色高度统一，辨识度极强。
    

### 三、核心元素设计原则（路由协议适配）

精准匹配OSPF、RIP、BGP等路由协议核心特性，元素贴合技术主题，不盲目套用科技特效：

- **拓扑逻辑贴合协议特性**：距离矢量协议（RIP）采用简单链式、阶梯式链路拓扑；链路状态协议（OSPF）采用网状、多节点环形拓扑；跨域协议（BGP）采用多区域、跨节点长线拓扑，逻辑贴合技术原理。
    
- **微光流线质感统一**：所有链路线条采用半透明柔光流光效果，线条细腻、亮度柔和，无粗硬边框、无刺眼高光，高级且不廉价。
    
- **节点分布均衡规整**：网络节点均匀分布，构图对称协调，不偏移、不拥挤，体现网络协议的规整性与逻辑性。
    
- **无多余装饰元素**：摒弃代码弹窗、图标贴纸、机械零件等无关元素，全程聚焦“网络、链路、拓扑”核心主题。
    

### 四、光影与质感原则（极简高级感）

- **低噪点纯净画质**：画面高清干净、无颗粒噪点、无模糊虚化，质感细腻通透，适配各类展示场景。
    
- **明暗层次柔和**：深色基底哑光沉稳，线条微光提亮，明暗对比适度，无强烈光影冲击，视觉舒适耐看，适合长期阅读学习类封面。
    
- **扁平化轻科技质感**：不写实、不立体重工业风，主打轻量化矢量科技质感，统一所有网络学习笔记的视觉调性。
    

### 五、系列区分与适配原则（和工业封面差异化）

- **场景差异化**：工业运维封面主打「实景工业+科技线条」厚重写实风；学习笔记封面主打「纯抽象拓扑+极简流光」清爽科技风，两类封面体系独立、互不冲突。
    
- **风格统一性**：延续相同暗调、无文字、16:9核心标准，整体视觉调性一致，属于同一系列技术封面，仅场景质感差异化区分。
    
- **精准适配场景**：专属网络协议学习、技术干货笔记、原理讲解、知识梳理类内容，不适用工程排障、企业项目、工业运维类主题。
    

### 六、硬性禁止细则（笔记版专属）

- 禁止冗余文字、杂乱水印、花哨贴纸、多余装饰图案、异形图标；仅允许极简规整的主题标题文字。
    
- 禁止工业实景、厂区设备、人物场景、生活化元素；
    
- 禁止高饱和亮色、暖色调、卡通插画、厚重特效；
    
- 禁止元素堆砌、画面拥挤、线条杂乱、光影刺眼；
    
- 禁止立体重工业质感、模糊滤镜、过度虚化效果。
